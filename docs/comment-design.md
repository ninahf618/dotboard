## 設計doc

## モデル：

| カラム  | 型     | 説明                     |
| ------- | ------ | ------------------------ |
| id      | Int    | コメントID・主キー       |
| itemId  | Int    | コメント対象のアイテムID |
| author  | String | コメントを書いた人の名前 |
| content | String | コメント文               |

## マイグレーション計画：

カラムは追加せず、新しいコメントテーブルを作成します。
コメントテーブルのitemIdはコメントを作成するときに指定します。
こうすることで、既存のアイテムテーブルを壊さずにマイグレーションできます。

## エンドポイント一覧

| メソッド | URL                     | リクエスト      | レスポンス         | ステータス |
| -------- | ----------------------- | --------------- | ------------------ | ---------- |
| GET      | /items/:itemId/comments | なし            | コメントの一覧     | 200        |
| POST     | /items/:itemId/comments | author, content | 作成されたコメント | 201        |

## 削除・編集を含めるかどうかの判断と理由

現状ではログイン機能がまだないので、コメントを書いた本人以外の人物が削除・編集する恐れがあるので、削除・編集は含めません。

## フロントでの見せ方

アイテム一覧の表示が混雑しないように、コメントはアイテムをクリックすると表示されるようにします。
