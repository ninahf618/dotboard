# API設計

## エンドポイント一覧

| メソッド | URL        | リクエスト                  | レスポンス      | ステータス      |
| -------- | ---------- | --------------------------- | --------------- | --------------- |
| GET      | /items     | クエリ（下記）              | 作品の配列      | 200 / 400       |
| GET      | /items/:id | なし                        | 作品1件         | 200 / 404       |
| POST     | /items     | title, note, rating, status | 作成した作品1件 | 201 / 400       |
| PATCH    | /items/:id | 変更したいフィールドだけ    | 更新後の作品1件 | 200 / 400 / 404 |
| DELETE   | /items/:id | なし                        | なし            | 204             |

## GET /items のクエリパラメータ

| 名前   | 値                        | 省略時     | 説明                                              |
| ------ | ------------------------- | ---------- | ------------------------------------------------- |
| tag    | タグ名                    | 絞り込まない | そのタグが付いた作品だけ返す                      |
| status | `open` / `doing` / `done` | 絞り込まない | その状態の作品だけ返す                            |
| sort   | `id` / `rating`           | `id`       | `id` は昇順、`rating` は高い順（同点は id 昇順） |

上記以外の値を渡すと 400 を返す。

## コメント

| メソッド | URL                     | リクエスト      | レスポンス         | ステータス      |
| -------- | ----------------------- | --------------- | ------------------ | --------------- |
| GET      | /items/:itemId/comments | なし            | コメントの配列     | 200 / 400 / 404 |
| POST     | /items/:itemId/comments | author, content | 作成したコメント1件 | 201 / 400 / 404 |

- コメントは `id` の昇順（投稿した順）で返す。
- `author` と `content` は前後の空白を除いて1文字以上が必要。満たさなければ 400 を返す。
- `:itemId` が数値でなければ 400、その作品が存在しなければ 404 を返す。
- 作品を削除すると、その作品のコメントも一緒に削除される。
- ログイン機能がないため、コメントの編集・削除は用意していない（理由は [comment-design.md](comment-design.md)）。
